# عين سجام – حزمة الصور الواضحة V3

لكل مشروع أربع طرق عرض منظمة:

1. `comparison_clear_before_latest.jpg`: مقارنة كبيرة قبل/أحدث صورة عالية الدقة.
2. `construction_progress_3_clear_stages.jpg`: ثلاث مراحل بناء بدون تكدس.
3. `timeline_5_stages_high_resolution.jpg`: خمس سنوات تاريخية من Sentinel-2.
4. `latest_high_resolution/`: صورتان حديثتان واضحتان، عامة وقريبة.

تعرض الواجهة المقارنة الكبيرة أولًا، ثم مراحل التنفيذ، ثم الصور المفردة داخل عارض تكبير. صور Sentinel-2 مؤرخة بدقة. تاريخ صورة World Imagery يختلف حسب الموقع، لذلك لا يوضع عليها عام إلا بعد التحقق من بيانات الخدمة.
