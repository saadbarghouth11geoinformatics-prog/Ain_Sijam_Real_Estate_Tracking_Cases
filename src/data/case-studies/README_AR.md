# حزمة دراسات حالة عين سجام

تضم الحزمة ست دراسات حالة سعودية، وفي كل مجلد:

- ثلاث صور Sentinel-2 حقيقية مؤرخة.
- لوحة مقارنة قبل/أثناء/بعد أو أحدث حالة.
- `case_study_ar.md` نص عربي جاهز لسابقة الأعمال.
- `project_data.json` بيانات منظمة للذكاء الاصطناعي.
- `sources.md` مصادر المشروع والصور.

## طريقة الدمج في المنصة

استخدم `catalog.json` لإنشاء بطاقات المشروعات. عند فتح البطاقة اعرض لوحة المقارنة، ثم الخط الزمني والصور المفردة، ثم خطوات المتابعة. أظهر المصدر والتاريخ ونسبة السحب تحت كل صورة.

## حدود الاستخدام

دقة Sentinel-2 مناسبة لمتابعة التغيرات الكبيرة في الموقع والطرق والكتل العمرانية، وليست مناسبة لإثبات تفاصيل صغيرة أو حدود ملكية مساحية. لا تعرض هذه الحالات على أنها أعمال نفذتها شركتك إلا إذا كانت لديك عقود ووثائق تثبت ذلك؛ يمكن عرضها كـ«نماذج متابعة توضيحية» أو «دراسات حالة عامة».
